# AGENTS.md

## Repo workflow rules

- Use **Conventional Commits** for every commit message.
  - Examples: `feat: ...`, `fix: ...`, `refactor: ...`, `chore: ...`.
- Prefer **one commit per file** when making changes.
- After preparing per-file commits, **push them together** as one batch.
- Keep changes small, focused, and easy to review.
- When fixing build issues, verify with a real build before committing.

## Notes for future work

- This repo is a forked mobile client base.
- Preserve upstream/history awareness when possible.
- If you touch Android build files, verify the APK build again before pushing.
